## PayU SOAP API Java SDK

This repository contains PayU MEA Java SDK and samples for SOAP API.

## Prerequisites
* Java JDK 17 or higher
* Support for TLS 1.2 

#### Gradle
```gradle
repositories {
	mavenCentral()
}
dependencies {
	compile 'co.za.payu.sdk:payu-mea-java-sdk:+'
}
```

## Get Started
- [Run Samples project](payu-mea-java-sample).
